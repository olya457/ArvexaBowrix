# Range Ledger

Offline-first React Native practice journal for archers. Users record observed
scores and conditions, maintain an equipment profile, review history and track
progress. The app avoids simulated measurements and professional equipment
recommendations.

## Structure

- `src/app` — application shell and navigation
- `src/core` — persistent state, models and statistics
- `src/features` — journal, equipment, insights and field guide
- `src/shared` — reusable interface components
- `src/assets/images` — original unchanged images
- `src/theme` — original unchanged color palette
